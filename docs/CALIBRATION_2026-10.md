# 校准记录 · 2026-10（基于 data/feedback 首批 66 次导出会话）

> 分析脚本为一次性离线脚本（未入库），本文档记录数据、方法、结论与最终配置。
> 数据窗口：2026-09-20 ~ 2026-10-17，66 个会话、2173 组、8934 张图。

## 1. 数据概况

- 组基本为 4 张/组（2132/2173），少量 12 张/组（同 prompt 多批次）。
- 用户行为：**接受推荐 795 组（36.6%）｜改选 1063 组（48.9%）｜整组弃选 315 组（14.5%）**。
- 全部会话 weights 一致（q0.8/a0.2，structure 影子），aesthetic 后端均为 shadow-v2 → 可比性好。
- 有 4 个会话出现「全组 selected==recommended」且组数 ≥10（共 160 组），疑似一键导出未逐组挑选；
  主结论用剔除这批的“干净集”（2013 组 / 1697 可用组）复核，两套数据结论一致。

## 2. 各特征与用户选择的关系

### 2.1 组内 pairwise（同组 被选 vs 未选，天然配对）

| 特征 | 严格胜率 win/(win+loss) | 备注 |
|---|---|---|
| composite（现行 q.8/a.2） | **0.672** | 现行综合分仍是最强单一信号 |
| aesthetic (shadow-v2) | **0.627** | 明显比 quality 强 |
| structure（影子分） | **0.575** | n=3755 对，信号真实存在 |
| sharpness | 0.577 | |
| quality | 0.575 | |
| structure.hands | 0.545 | |
| 结构 flag 数（越多越好？） | 0.429（反向） | flag 多 → 不被选，符合预期 |

要点：
1. **aesthetic 是最有区分度的特征**（组内 std 0.119，quality 只有 0.022 —— 同 prompt 同底模下
   quality 几乎拉不开差距，但 aesthetic 能）。
2. **structure 影子分有效**：被选图均分 0.911 vs 未选 0.893；被选 vs 整组弃选 Mann-Whitney
   z=4.69（p<0.0001）。达到了 FEEDBACK_FORMAT.md 预设的转正统计门槛。
3. quality 的价值不在“排序”而在“剔除”：见 2.2。

### 2.2 质检 flag 与整组弃选

- 「偏糊」flag：被选图中出现率 1.5%（27/1858），未选 1.7%，**整组弃选组内成员 5.2%**（62/1258）。
- 整组弃选的组：mean sharpness 0.351 vs 接受的组 0.729 —— **弃选组几乎都是“糊图组”**。
- 组级规则 `mean(sharpness) < 0.45`：捕获 65% 的整组弃选，误报 23%（基线 14.5%，≈2.2x lift）。
  精度只有 ~34%，**不足以自动弃选，但足够做 UI 提示**。

### 2.3 结构 flag 细分

出现率差异（被选% vs 未选%）最大的 flag：右/左手指尖聚集(并指嫌疑)（8.2%/11.1%、6.2%/8.7%）、
手指长度顺序异常（5.3%/6.0%、4.6%/6.1%）。方向全部正确但幅度小 → 支持“低权重连续分”，
不支持“按 flag 硬扣分”（实验：分级 flag 惩罚把 top-1 命中从 42.8% 打到 38.8%，**负优化**）。

## 3. 候选算法离线评测（top-1 命中 = 推荐==用户实际选择）

在全量可用组（n=1857）与干净集（n=1697）上重放打分：

| 配置 | clean-hit | clean 推荐带严重结构flag率 | full-hit |
|---|---|---|---|
| 现行 q.8/a.2（structure 影子） | 0.3736 | 20.1% | 0.4276 |
| + qpen0.25 | 0.3754 | 19.9% | 0.4292 |
| **+ s0.05 + qpen0.25（选定）** | **0.3795** | **17.9%** | 0.4254 |
| + s0.1 + qpen0.25 | 0.3765 | 16.7% | 0.4200 |
| + s0.2 | 0.3683 | 14.7% | — |

其他被否决的方案（clean 集全部 ≤ 基线）：
- z-score 组内归一化 + 各种权重（0.386~0.395）；
- Plackett-Luce listwise 学习排序（5-fold CV 0.368 < 基线 0.374，且不可解释）；
- 几何平均/乘积形式（0.380）；
- structure 做 top 邻近 tie-break（eps≥0.01 全部负优化）；
- 提高 aesthetic 权重到 0.5+（0.354，pairwise 强但 top-1 反而差——因为 composite 里 quality 的
  微小差距经常是正确的“一票否决”信号）。

结论：**现行线性加权框架已接近该特征集的天花板**（~0.38 clean / ~0.43 full）。
增益来自三个小修正，而不是换模型：
1. structure 转正、给低权重 0.05（命中 +0.6pp，推荐图带严重结构问题率 −2.2pp）；
2. 质检 flag 平坦惩罚 0.25（糊图硬降权；用户 29 次选了带 flag 的图 vs 命中增益为正）；
3. 组级「疑似整组弃选」提示（只提示不干预，把 65% 的弃选组提前标出来，省点击）。

## 4. 最终生效配置（config/curator.example.yaml）

```yaml
weights: {quality: 0.8, aesthetic: 0.2, structure: 0.05, vlm_judge: 0.0}
quality_flag_penalty: 0.25
suspect: {mean_sharpness_below: 0.45}
structure: {shadow: false, ...}
```

对应代码改动：
- `curator/pipeline.py`：composite 计算后对带质检 flag 的成员减 `quality_flag_penalty`；
  scan 后对每组计算 `suspect` 提示（组平均 sharpness 阈值）；反馈 schema 升为 `aic.feedback.v1.1`
  （新增 `quality_flag_penalty`、group.`suspect` 字段，旧字段不变）。
- `curator/static/index.html`：组头显示「⚠ 疑似整组弃选」tag；结构分 chip 的 tooltip
  依据实际 shadow 状态显示；顶部提示语同步。
- structure 打分器逻辑未动（转正只是配置开关），影子模式随时可用 `shadow: true` 退回。
